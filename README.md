# 💾 WinDiskAnalyzer

Анализатор дискового пространства для Windows с визуализацией через **Treemap** и **Sunburst** диаграммы. Вдохновлён WinDirStat и Scanner (от Steffen Gerlach) , написан с нуля на C# и WPF.

<img width="1568" height="836" alt="image" src="https://github.com/user-attachments/assets/3d80663c-1392-48dc-af73-b662a23b95b2" />

## ✨ Возможности

- Быстрое сканирование файловой системы (рекурсивный обход)
- **Treemap** — древовидная карта с подсветкой файлов по расширениям
- **Sunburst** — круговая диаграмма структуры папок
- Интерактивное выделение веток при наведении на дерево
- Тёмная / светлая тема

## 🛠️ Технологии

- C# 12 / .NET 10
- WPF (Windows Presentation Foundation)
- Архитектура MVVM
- Custom WPF Controls

## 🚀 Установка

Скачай последнюю версию `.exe` в разделе **[Releases](../../releases)**.

*Возможно Windows попросит поставить .NET10*
