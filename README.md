# 💾 WinDiskAnalyzer

(ru)

Анализатор дискового пространства для Windows с визуализацией через **Treemap** и **Sunburst** диаграммы. Вдохновлён WinDirStat и Scanner (от Steffen Gerlach) , написан с нуля на C# и WPF.

(en)

Disk space analyzer for Windows with visualization via **Treemap** and **Sunburst** charts. Inspired by WinDirStat and Scanner (by Steffen Gerlach), written from scratch in C# and WPF.

## ✨ Возможности / Possibilities 
(ru)
- Быстрое сканирование файловой системы (рекурсивный обход)
- **Treemap** — древовидная карта с подсветкой файлов по расширениям
- **Sunburst** — круговая диаграмма структуры папок
- Интерактивное выделение веток при наведении на дерево
- Тёмная / светлая тема

(en)
- Fast file system scan (recursive traversal)
- **Treemap** - tree map with file extension highlighting
- **Sunburst** - pie chart of folder structure
- Interactive highlighting of branches when hovering over a tree
- Dark/light theme


## 🛠️ Технологии / Technologies 

- C# 12 / .NET 10
- WPF (Windows Presentation Foundation)
- Архитектура MVVM
- Custom WPF Controls
